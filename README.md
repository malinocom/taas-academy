# آکادمی تاس — نسخه بازطراحی‌شده

این بسته شامل فرانت‌اند و بک‌اند سامانه آکادمی تاس است.

## ساختار

- `frontend/` — وب‌سایت عمومی، پنل دانش‌آموز، پنل مشاور و پنل مدیریت
- `backend/` — API، احراز هویت، مدیریت آزمون‌ها، برنامه خصوصی، سفارش‌ها، رقابت‌ها و آپلود فایل

## تغییرات این نسخه

- بازطراحی یکپارچه رابط کاربری با پالت آبی آسمانی، فیروزه‌ای و سفید
- بازطراحی صفحه اصلی، سربرگ، پاورقی، کارت‌ها، فرم‌ها، پنل‌ها و حالت موبایل
- افزودن صفحه راهنما و دسترسی سریع به بخش‌های سامانه
- داشبورد مدیریتی با آمار سامانه، موارد نیازمند پیگیری و میانبرهای عملیاتی
- تکمیل دسترسی سریع پنل دانش‌آموز و نمایش بخش رقابت مطالعاتی
- اصلاح نمایش PDF آزمون و بازسازی چیدمان آزمون PDF/بانک سؤال
- اصلاح ارسال `multipart/form-data` برای آپلود PDF، تصویر جزوه و گزارش کار
- افزودن آپلود و پیش‌نمایش امن PDF جزوه در فروشگاه؛ دسترسی خریدار پس از تأیید سفارش توسط مدیر فعال می‌شود
- اصلاح مسیر ذخیره و آدرس عمومی فایل‌ها در بک‌اند، محدودیت حجم/تعداد و اعتبارسنجی نوع فایل
- بهبود CORS و اعتماد به reverse proxy برای کوکی‌های امن
- افزودن تنظیمات آماده انتشار SPA و metadata پایه SEO

## اجرای محلی

ابتدا متغیرهای محیطی بک‌اند را بسازید:

```bash
cd backend
npm ci
cp .env.example .env
# مقادیر دیتابیس، کلیدهای JWT و رمز مدیر را در .env تنظیم کنید.
npx prisma generate
npx prisma db push
npm run dev
```

سپس در ترمینال دیگر فرانت‌اند را اجرا کنید:

```bash
cd frontend
npm ci
cp .env.example .env
npm run dev
```

## انتشار

برای انتشار فرانت‌اند، پوشه `frontend/` را به‌عنوان ریشه پروژه Vite منتشر کنید (`npm run build`، خروجی `dist/`). در محیط Production مقدار `VITE_API_URL=https://backend-taas.runflare.run` را تنظیم کنید. فایل `frontend/vercel.json` برای مسیرهای داخلی React Router آماده شده است.

بک‌اند باید جداگانه روی سرویسی با Node.js و PostgreSQL اجرا شود. فایل `backend/.env.example` متغیرهای موردنیاز را توضیح می‌دهد. در Production، `NODE_ENV=production`، `COOKIE_SECURE=true`، `FRONTEND_ORIGINS` برابر دامنه واقعی فرانت‌اند و `BACKEND_URL` برابر دامنه API باشد.

## نکات ضروری پیش از انتشار نهایی

1. فایل‌های `.env` عمداً داخل بسته قرار نگرفته‌اند؛ اطلاعات محرمانه باید در تنظیمات امن میزبان وارد شوند.
2. `FRONTEND_ORIGINS` در بک‌اند باید دقیقاً دامنه نهایی فرانت‌اند باشد.
3. `BACKEND_URL` باید آدرس عمومی API باشد تا لینک PDF و تصاویر به دامنه درست اشاره کنند.
4. برای کوکی ورود در محیط HTTPS، `COOKIE_SECURE=true` تنظیم شود.
5. پوشه `UPLOAD_DIR` باید persistent باشد؛ در غیر این صورت PDFها و تصاویر با حذف دیسک موقت میزبان از دست می‌روند.
6. پس از دریافت این نسخه، برای اضافه‌شدن فیلدهای PDF جزوه به دیتابیس، یک‌بار `npx prisma db push` در پوشه `backend/` اجرا شود.
7. برای جایگزینی سایت روی `taas.runflare.run` باید فایل‌های `dist/` روی همان هاست فعلی منتشر شوند. انتشار روی دامنه‌ای مانند Vercel نیازمند افزودن آن دامنه به CORS و هماهنگ‌کردن کوکی‌های بک‌اند است.
