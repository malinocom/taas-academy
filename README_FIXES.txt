تغییرات انجام‌شده
=================

1) تراز آزمون
- محاسبه درصد در هر دو حالت Question Bank و PDF بر اساس نمره منفی اصلاح شد.
- فرمول نمره منفی: netCorrect = correct - wrong / wrongPerPenalty
- درصد نهایی: percent = round((netCorrect / total) * 100)
- تراز آزمون بعد از ثبت هر attempt برای کل شرکت‌کنندگان همان آزمون دوباره محاسبه می‌شود.
- فرمول تراز: taraz = max(4000, round(5000 + 2000 * z))
- z = (percent - mean) / standardDeviation
- کف تراز روی 4000 تنظیم شده است.
- تراز در کارنامه، تحلیل دانش‌آموز، لیست نتایج ادمین و PDF نمایش داده می‌شود.

2) شرکت مجدد
- خطای شرکت مجدد به این دلیل بود که فرانت‌اند route مربوط به /admin/exams/:examId/retakes را صدا می‌زد ولی بک‌اند چنین routeای نداشت.
- GET و POST برای مدیریت مجدد آزمون اضافه شد.

3) شاگردان خصوصی موسسه
- نقش جدید advisor اضافه شد.
- ادمین می‌تواند مشاور بسازد.
- ادمین می‌تواند برای دانش‌آموز خصوصی مشاور و تاریخ تمدید مشخص کند.
- صفحه شاگردان خصوصی حالا لیست مشاورها را نشان می‌دهد و برای هر مشاور شاگردها و تاریخ تمدید نمایش داده می‌شود.
- پنل مشاور اضافه شد: /advisor
- مشاور فقط شاگردهای خودش را می‌بیند و می‌تواند برای هرکدام برنامه بنویسد.
- برنامه بعد از ذخیره مستقیم در پنل دانش‌آموز قابل مشاهده است.

4) برنامه دانش‌آموز
- دانش‌آموز فقط تا 3 روز آینده را می‌تواند ببیند.
- روزهای قبل محدودیتی ندارند.
- بالای برنامه اطلاعات دانش‌آموز، مشاور، پایه، شماره تماس و تاریخ تمدید نمایش داده می‌شود.
- فرم برنامه‌نویسی برای ادمین و مشاور بزرگ‌تر و قابل استفاده‌تر شد.

دستورات لازم بعد از deploy
=========================

Backend:
1. npm install
2. npx prisma generate
3. npx prisma db push
4. npm run build
5. npm run start

Frontend:
1. npm install
2. npm run build:frontend

نکته:
در این محیط، دانلود engineهای Prisma از binaries.prisma.sh انجام نشد؛ بنابراین validate/generate واقعی Prisma اینجا اجرا نشد. فرانت‌اند با TypeScript و Vite build تست شد و موفق بود. بک‌اند با stub موقت Prisma فقط از نظر TypeScript/Syntax بررسی شد؛ در سرور واقعی باید حتما prisma generate و db push اجرا شود.
