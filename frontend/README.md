# آکادمی تاس — سامانه مشاوره و آموزش تحصیلی

سامانه فرانت‌اند آکادمی تاس با React، TypeScript، Vite و Tailwind CSS.

## امکانات سامانه

- وب‌سایت عمومی، معرفی خدمات، مشاوران، دوره‌ها، فروشگاه جزوه و راهنمای استفاده
- ثبت‌نام و ورود دانش‌آموز، مشاور و مدیر
- آزمون آنلاین از بانک سؤال و آزمون PDF، تایمر، پاسخ‌برگ، کارنامه و تحلیل
- پنل مدیریت برای آزمون‌ها، بانک سؤال، دانش‌آموزان، مشاوران، دانش‌آموزان خصوصی، برنامه‌ریزی، رزرو مشاوره، سفارش‌ها، جزوه‌ها، رقابت‌ها و گزارش کار
- پنل دانش‌آموز برای نتایج، برنامه اختصاصی، گزارش کار، سفارش‌ها و رقابت مطالعاتی
- پنل مشاور برای مشاهده شاگردان خصوصی و ثبت برنامه روزانه

## اجرای محلی

```bash
npm ci
cp .env.example .env
npm run dev
```

مقدار `VITE_API_URL` باید به آدرس بک‌اند فعال متصل باشد. مقدار فعلی نمونه:

```env
VITE_API_URL=https://backend-taas.runflare.run
```

## ساخت نسخه انتشار

```bash
npm run build
```

فایل‌های آماده انتشار در پوشه `dist/` ساخته می‌شوند.

## انتشار روی Vercel

- ریشه پروژه را روی پوشه فرانت‌اند قرار دهید.
- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm ci`
- متغیر محیطی `VITE_API_URL` را برای Production و Preview تنظیم کنید.

فایل `vercel.json` مسیرهای داخلی React Router را به `index.html` هدایت می‌کند.

## نکته مهم اتصال بک‌اند

این پروژه فرانت‌اند است و اطلاعات کاربران، آزمون‌ها، سفارش‌ها، رزروها و برنامه‌های خصوصی را از بک‌اند موجود دریافت می‌کند. برای انتشار روی دامنه‌ای جدید، دامنه فرانت‌اند باید در CORS بک‌اند مجاز باشد. چون ورود بر پایه کوکی نشست انجام می‌شود، تنظیمات کوکی و دامنه نیز باید با دامنه نهایی هماهنگ شوند. تغییر دامنه بدون تنظیم بک‌اند ممکن است باعث اختلال در ورود یا آپلود فایل شود.

## رفع مشکل PDF

آپلودهای `multipart/form-data` اکنون بدون تبدیل به JSON ارسال می‌شوند و پیش‌نمایش PDF از نمایشگر داخلی مرورگر استفاده می‌کند تا به بارگذاری worker خارجی وابسته نباشد.
